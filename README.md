# 不听听力资料仓库

用于整理以后发布到 GitHub 的听力资料。一组配套音频资料放在一个独立文件夹中，文件夹名称包含考试或课程类型，方便以后增加英语四级及其他语言。

## 文件夹命名

成套考试资料使用：`考试名称_年份年月份月_套数`。

示例：

- `英语六级_2025年12月_第一套`
- `英语六级_2025年6月_第二套`
- `英语四级_2025年12月_第一套`

月份不补前导零；套数使用中文，如第一套、第二套、第三套。每一组配套资料使用独立目录，不混放到其他套数中。

独立散句用音频内容的核心词命名，例如 `ClimateChange`、`环境保护`。同名资料使用编号区分，例如 `ClimateChange_01`、`ClimateChange_02`。

## 每个子文件夹只保留三份文件

“原文”指原始录音文件。录音不重新编码，保留来源提供的 MP3 或 M4A 格式。以 `英语六级_2025年12月_第一套` 为例：

| 文件 | 用途 |
| --- | --- |
| `英语六级_2025年12月_第一套_原文.mp3` | 完整原始录音，按 SHA-256 校验与来源文件一致 |
| `英语六级_2025年12月_第一套_译文.txt` | 英文原文和中文参考译文，按段落对照，使用 UTF-8 编码 |
| `英语六级_2025年12月_第一套_时间标记.json` | 单句英文、中文、段落关联、起止时间、来源、许可、音频哈希和核验记录 |

保留来源文件名和原始字节。少数来源虽以 MP3 命名，实际容器是 MP4/AAC 或裸 AAC，`audio.codec` 和 `audio.containerFormat` 记录实际检测结果，播放器按真实格式解码。不另存单句音频，应用按时间标记播放完整录音中的对应区间。

时间标记必须对应本目录中的实际录音版本。更换或裁剪音频后，应重新核验时间标记，并一起更新版本信息。现有时间标记基于压缩录音生成，导出时解码原始录音与压缩录音，在每个听力部分抽查开头、中间、结尾的语音波形，核验时间轴并记录偏移量。

## 文本与句子的对应

- `paragraphs` 保存完整英中对照段落，`sentences` 保存用于单句播放的英文与起止时间。
- 每句用稳定的 `id` 标识，并用 `paragraphId` 关联所属段落。随机一句、再听一遍、显示原文和译文时，应始终使用同一条句子记录。
- 原译文为整段时，保留整段译文，`translationScope` 为 `paragraph`，显示标签为“所在段译文”。不按中文标点猜测单句译文，也不声称整段内容只对应这一句。
- 一个段落只有一句时，`translationScope` 为 `sentence`。现有译文包含机器参考译文，未经全面人工校订，非官方答案。
- `sourceTranscript` 另保留来源英文文件的完整内容。已有来源覆盖两篇长对话、两篇短文、三篇讲座；录音中的考试说明、报题等未在英文材料中列出的内容不进入随机练句池。
- 起止时间单位为秒，起点是完整音频解码后的起点，终点不包含在播放区间内。播放器需要核对文件哈希及解码器时间轴；直接按 MP3 文件字节截取不能保证句子边界正确。
- MP3 和裸 AAC 的 `packetIndex` 保存经 FFprobe 核验的每帧字节位置、长度和采样数，使用 zlib 压缩、Base64 编码，小端 `<qii>` 格式。裸 AAC 索引指向去除 ADTS 头后的帧载荷，并保存 `audioSpecificConfig`。MP3 的 `leadingSkipSamples` / `trailingDiscardSamples` 保留解码时间轴修正信息。普通 M4A 使用容器自带时间戳。
- 帧索引用于绕过系统 MP3 按估算码率跳转产生的秒级漂移。客户端应先解码前导帧，再按时间戳裁切输出，不能只按字节切片直接播放。
- 现有标记是自动声学对齐，保留置信度和边界警告；核验通过不等于每句都经过人工听审。

## 根目录文件

`catalog.json` 提供 29 组资料的路径、哈希、录音长度与句子数量，便于后续应用加载。`SOURCE-LICENSE.md` 保留来源授权说明。

音频及英文资料来自 [Ysoseri1224/CET-6-Listening-10-Years-Resources-and-Analysis](https://github.com/Ysoseri1224/CET-6-Listening-10-Years-Resources-and-Analysis)，固定版本为 `42fc6658e0b4a3dbae06755ba105d79169820576`，资源文件采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。每份时间标记和译文也保留来源署名。

2025 年 6 月和 2023 年 12 月的两组来源录音套号与英文原文编号互换，导出时按已核对的实际内容修正，目录套号以英文材料为准。

## 本地空间与维护

同一 D 盘上的录音优先通过硬链接复用已有原始录音，避免再复制约 727 MB 音频；上传工具可以正常读取完整内容。硬链接共享文件内容，维护时不要直接改写录音；需要替换时，先移除该目录下的链接，再放入新文件，并重新制作标记。删除一处硬链接不会删除其他位置仍保留的文件。

整理工具：`../listening-android/tools/export-github-library.py`，导出后补充精确帧索引：`../listening-lab/tools/index-repository-audio.py`。原始资料核验报告：`../listening-android/.qa/github-original-validation.json`。

## 当前状态

已填入现有公开来源提供的 2019—2025 年共 29 组配套资料，每个子目录恰好三份文件，共 4,507 条单句时间标记。已核验原始音频与英文来源哈希、文本覆盖、时间顺序与边界，并抽查 609 处原始／压缩录音波形，时间轴一致。

这些资料不代表所列年份所有官方套卷。远程仓库为 [happypotato2024/buting-listening-resources](https://github.com/happypotato2024/buting-listening-resources)，实际发布内容以远程文件和提交记录为准。不听听力测试版 v0.3.0 直接加载这些预处理资料，按不可变提交和 SHA-256 绑定版本；刷新失败保留原目录。时间标记仍是自动对齐结果，译文包含未经全面人工校订的机器参考译文。
